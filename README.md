# Diwali Magic 2026 — by Kanhaiya Mishra

A responsive, cinematic Diwali greeting website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and content
- `style.css` — luxury dark + royal gold theme, responsive layout and animations
- `script.js` — surprise modals, wish generator and canvas fireworks

## Run locally
Open `index.html` in a browser. For the best experience, use a local development server (for example VS Code Live Server).

## Publish with GitHub Pages
1. Create a new public GitHub repository named `diwali-magic-2026`.
2. Upload `index.html`, `style.css`, `script.js`, and this README (keep the three code files in the repository root).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then Save.
6. Wait for GitHub Pages to publish the site. The live URL will appear in the Pages section.

## Customize
Edit the message text in the `messages` object in `script.js`.
Change the name in `index.html` if needed.

## Images and fonts
The design loads remote images from Unsplash and fonts from Google Fonts. An internet connection is required for those assets. Image URLs can be replaced with your preferred licensed images.
